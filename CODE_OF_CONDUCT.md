# Code de conduite

Hangar est un projet ouvert à tous. Dans les issues, les pull requests et partout où le projet échange, on attend de chacun :

- du respect, quels que soient le niveau, l'origine, le genre, l'âge ou les opinions des autres ;
- des critiques sur le code et les idées, jamais sur les personnes ;
- de la patience avec les débutants et les questions déjà posées.

Ne sont pas acceptés : insultes, harcèlement, propos discriminatoires, publication d'informations privées sur quelqu'un, spam.

## Signaler un comportement

Utilise les outils de signalement de GitHub (« Report content » sur un message, ou le signalement privé de l'onglet **Security** du dépôt). Le mainteneur peut masquer ou supprimer un message, verrouiller une discussion et bloquer un compte qui ne respecte pas ce code.

Ce code s'inspire du [Contributor Covenant](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).
